# Portfólio Profissional — Kamila Luedy

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, habilidades técnicas e projetos na área de Dados, BI e Desenvolvimento Web.

## Sobre

Este projeto é um site estático construído com HTML, CSS (Tailwind) e JavaScript puro, sem frameworks ou dependências de build. O design é responsivo, com tema escuro e elementos visuais modernos.

## Seções

- **Sobre Mim** — apresentação profissional e estatísticas de carreira
- **Tech Stack** — habilidades técnicas com indicadores de proficiência
- **Experiência** — timeline da trajetória profissional
- **Formação** — graduação, pós-graduação e certificações
- **Projetos** — seleção de trabalhos desenvolvidos
- **Contato** — formulário de contato integrado com EmailJS

## Tecnologias

- HTML5
- CSS3 + Tailwind CSS
- JavaScript
- Lucide Icons
- EmailJS
- Google Fonts (Space Grotesk + JetBrains Mono)
